## Task 4: Social Media Sentiment Analysis

Analyzed and visualized sentiment in social-media text to understand public opinion about topics, products, and brands.

### Objective

Convert raw social-media text and sentiment labels into interpretable patterns that describe audience perception and emotional tone.

### Workflow

1. Loaded the training and validation datasets.
2. Inspected sentiment labels and prepared the text data.
3. Analyzed sentiment distribution and recurring patterns.
4. Created visualizations to communicate public-opinion trends.

## Running the Notebook

1. Clone or download this repository.
2. Keep the dataset file in the same directory as the notebook.
3. Open the notebook in Jupyter Notebook, JupyterLab, VS Code, or Google Colab.
4. Install any missing Python dependencies.
5. Run the cells in sequence to reproduce the analysis.
